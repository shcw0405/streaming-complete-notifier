# Demo 录屏与剪辑清单

## 录制前准备

- 浏览器缩放设置为 100%，关闭书签栏和无关扩展图标。
- 系统开启桌面通知，并设置为录屏时可见。
- 将 ChatGPT、Gemini、Grok、AI Studio 登录完成。
- 在扩展设置中打开通知、提示音和需要演示的平台。
- 准备一个没有隐私内容的演示账号或新对话。
- 清理桌面、通知中心、标签页标题和终端历史中的隐私信息。
- 使用 1920×1080、30 fps 录制；鼠标指针不要过快。
- 每个关键动作前后额外停留 2 秒，给剪辑留余量。
- 真实提示音单独录一份，另保留 `src/javascript/audio/streaming-complete.mp3` 作为后期备用。

## 推荐演示提示词

选择稳定、无敏感信息、生成时间略长的任务：

> 请比较“同步等待 AI 完成”和“异步接收完成通知”两种工作方式，从注意力切换、响应及时性和多任务协作三个角度，整理成一张表，并给出三条结论。

如果生成过快，可使用：

> 请先分析任务，再输出一份结构完整的方案：设计一个由研究、设计、开发三个 AI Agent 协作完成产品原型的工作流，列出各阶段输入、输出、需要人决策的节点和失败处理方式。

## 必须录制的 8 个原始镜头

1. `01-submit`：在 ChatGPT 提交任务并开始生成，10–15 秒。
2. `02-switch-away`：切换到文档或代码窗口继续工作，8–10 秒。
3. `03-notification`：系统通知真实出现并播放提示音，至少保留 5 秒。
4. `04-click-back`：点击通知并返回正确对话，8–10 秒。
5. `05-popup`：打开扩展设置页，缓慢展示主要开关，8 秒。
6. `06-multi-platform`：Gemini、Grok、AI Studio 各录一段完成状态，单段 5 秒。
7. `07-image`：录制一次 ChatGPT 图片任务完成或准备已有素材，8 秒。
8. `08-terminal`：Claude Code 或 Codex 结束任务后收到提醒，8–10 秒。

## 可选技术镜头

- `background.js` 中的平台配置快速特写。
- `pageHook.js` 中流式响应解析的代码特写。
- `visibilitySpoof.js` 中后台可见状态处理的代码特写。
- Git 提交历史中的六个里程碑。

技术镜头只用于证明实现深度，每段不超过 3 秒。

## 剪辑验收

- 前 30 秒是否明确表达痛点和项目价值？
- 90 秒内是否出现一次真实的“通知—点击—返回任务”闭环？
- 是否保留了真实提示音？
- 是否清楚区分现有功能与未来设想？
- 评委内容是否标注为“意见摘要”，没有伪造逐字引语？
- 是否避免长时间滚动代码或逐个讲设置？
- 成片是否控制在 4 分 15 秒至 4 分 45 秒？
- 字幕中的 ChatGPT、Gemini、Grok、AI Studio、Agent 拼写是否一致？
