FAQ

常见问题

会不会监听我和 AI 的对话？
扩展只读你自己刚发出去的提问前 35 字（用作通知标题）。AI 的回答内容不会被读取。代码全开源在 GitHub，可以自己审。
和 ChatGPT 自带的"完成通知"有什么区别？
ChatGPT 原生通知只在切走标签页好几分钟后才响，且无法点击跳回。我们是任何时候都响、点击直接跳回那条对话，并且还覆盖另外 3 个平台。
终端跑 Claude Code 也想响一声？
能。复用本仓库提示音 + terminal-notifier，Claude Code 跑完一轮任务自动叮 + 点击跳回 VSCode / iTerm。详见 README 彩蛋章节。
支持 Edge 吗？
支持。Chrome 和 Edge（建议 116+）都可以，Windows / macOS / Linux 通用。
