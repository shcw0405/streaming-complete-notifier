## 😩 Problem（戳痛点）

你发了句 prompt，AI 开始思考。

你想着"反正还要等三分钟"，顺手切到了知乎。

半小时后你想起来——

**那条对话还开着。答案早就写完了，凉透了。**

注意力被切走就回不来了。要么死盯进度条浪费一下午，要么彻底分心忘了最初要干嘛。**两头都不讨好。**

## ✨ Solution（一句话说清你做了啥）

**一个 Chrome 扩展，只做一件事：AI 答完的瞬间，给你一声桌面通知 + 提示音。**

3 个能让你立刻续上的细节：

- **看得见是哪条**：通知标题直接显示你刚刚提问的前 35 字，一秒认出哪条对话出结果。
- **思考结束就提前响**：ChatGPT 的 o1 / o3 推理模型，思考刚结束就先响一次，比首字符还早。
- **点一下回到现场**：点击通知自动拉起对应标签页，不用从一堆 tab 里翻。

## ❓ FAQ（顺手挡掉常见疑虑）

**Q：会不会监听我和 AI 的对话？**
扩展只读你**自己刚发出去**的提问前 35 字（用作通知标题）。AI 的回答内容**不会被读取**。代码全开源在 GitHub，可以自己审。

**Q：和 ChatGPT 自带的"完成通知"有什么区别？**
ChatGPT 原生通知只在切走标签页好几分钟后才响，且无法点击跳回。我们是**任何时候都响、点击直接跳回那条对话**，并且还覆盖另外 3 个平台。

**Q：终端跑 Claude Code 也想响一声？**
能。复用本仓库提示音 + `terminal-notifier`，Claude Code 跑完一轮任务自动叮 + 点击跳回 VSCode / iTerm。详见 README。

## 文案笔记（why this angle）

- **整体框架**：Hero 用好奇派标题制造悬念；Problem→Solution 用 PAS 戳痛 → 给解药；FAQ 主动挡掉"会不会偷数据"和"和原生通知有啥区别"两个最常见的退出点。
- **沿用现有 README 的"摸鱼"语气**，但落地页比 README 更动作导向（README 是给 GitHub 访客看的，落地页是给"还没装"的人看的）。
- **关键差异化**没用"先进、智能、强大"这种 skill 禁用的形容词，全部用具体数字 / 行为代替（35 字、<2s、3 个细节、4 个平台）。
- **A/B 建议**：紧迫派标题在付费用户群可能更猛，但开源工具更适合好奇派。次 CTA 的"GitHub Star"只对开发者群体有吸引力，可针对非开发者落地页换成"看看代码长啥样"等更轻的次级动作。
- **没写社会证明区**：项目目前没有可信的用户数 / Star 数可引用，强行编不可信，等有真实数据再补"Trusted by N developers"那一栏。
